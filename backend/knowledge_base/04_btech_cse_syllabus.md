# B.Sc. in Computer Science and Engineering - Syllabus Outline

The Bachelor of Science in Computer Science and Engineering at Greenfield University is a 4-year program of 148 credit hours divided into 8 semesters.

## Year 1 (Foundation)

- Semester 1: Programming Fundamentals (CSE-1101), Discrete Mathematics (MAT-1102), English Composition (ENG-1101), Physics (PHY-1101)
- Semester 2: Object Oriented Programming (CSE-1201), Data Structures (CSE-1202), Linear Algebra (MAT-1201), Digital Logic Design (CSE-1203)

## Year 2 (Core Computer Science)

- Semester 3: Algorithms (CSE-2101), Database Management Systems (CSE-2102), Computer Architecture (CSE-2103), Statistics and Probability (STA-2101)
- Semester 4: Operating Systems (CSE-2201), Computer Networks (CSE-2202), Theory of Computation (CSE-2203), Microprocessor and Interfacing (CSE-2204)

## Year 3 (Advanced Topics)

- Semester 5: Software Engineering (CSE-3101), Compiler Design (CSE-3102), Web Technologies (CSE-3103), Numerical Methods (MAT-3101)
- Semester 6: Artificial Intelligence (CSE-3201), Computer Graphics (CSE-3202), Mobile Application Development (CSE-3203), Elective I

## Year 4 (Specialization)

- Semester 7: Machine Learning (CSE-4021), Deep Learning (CSE-4022), Information Security (CSE-4023), Elective II
- Semester 8: Internship or Industrial Attachment (CSE-4100, 6 credits) and the final year Project (CSE-4101, 4 credits)

Each theory course carries 3 credit hours and each lab course carries 1.5 credit hours. The minimum CGPA required for graduation is 2.50 out of 4.00. The Machine Learning course CSE-4021 is a prerequisite for the Deep Learning course CSE-4022.
